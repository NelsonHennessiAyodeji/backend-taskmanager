# Task Management REST API

A simple RESTful API for managing tasks. This project was developed as part of a Backend Intern Technical Case Study.

The API allows users to create, retrieve, update, filter, and delete tasks.

---

## Technologies Used

- Node.js
- TypeScript
- Express.js
- MongoDB
- Mongoose
- dotenv
- tsx

---

## Features

- Create tasks
- Retrieve all tasks
- Retrieve a single task
- Update tasks
- Delete tasks
- Filter tasks by status
- Validate incoming data
- Validate task IDs
- Handle non-existent tasks
- Centralized error handling
- Appropriate HTTP status codes
- MongoDB persistence

---

# Getting Started

## Prerequisites

Before running the project, make sure you have:

- Node.js installed
- npm installed
- A MongoDB database (MongoDB Atlas or local MongoDB)
